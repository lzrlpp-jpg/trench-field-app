# 探槽野外编录

可安装到手机主屏幕的离线网页应用。支持多个工程切换、本机自动保存、导尺数据与多个关联槽型测点、地质分层、刻槽样照片、工程量汇总和按 CYPM15-1 表格字段生成 Word、PDF、Excel。照片按样品关联，改样品编号后照片名称同步更新；照片随 JSON 备份导出和恢复。

## 在电脑上打开

1. 安装 Python 3（若电脑已有 Python，可跳过）。
2. 双击 `启动应用.bat`，保持弹出的命令窗口运行。
3. 在电脑浏览器访问 `http://localhost:8765`。

如果双击 `start-local.ps1` 后看到的是脚本代码，请关闭文本编辑器，改为双击 `启动应用.bat`。也可以在 PowerShell 中运行 `.start-local.ps1`。

这个本地地址便于预览和录入；应用数据保存在当前浏览器。换浏览器、清除浏览器数据或换设备前，先在“导出与备份”下载 JSON 备份。

## 在手机上安装

将本文件夹内全部静态文件发布到一个可访问的 HTTPS 网站，再用手机浏览器打开网站。网页顶部的“安装到手机”按钮会显示对应系统说明；Android Chrome/Edge 可用安装弹窗或浏览器菜单安装，iPhone/iPad 请在 Safari 的分享菜单选择“添加到主屏幕”。应用清单提供矢量应用图标，Service Worker 会缓存所需静态文件；安装后可离线录入与导出。若不部署网站，亦可在手机浏览器访问局域网内的网页地址进行临时使用，但离线安装能力取决于浏览器是否允许该地址使用 Service Worker。

## 现场录入顺序

1. 在“工程概况”填写矿区、工程编号、日期、编录人与采样人。不同探槽可用“新建工程”分别保存，再用工程列表切换。
2. 在“导尺数据”按测量顺序新增导尺段，记录导尺编号、本段斜距、方位角、坡度角和端点坐标。导尺斜距按段累计一次。
3. 在对应导尺段下新增一个或多个“槽型测点”，填写测点编号及其在本导尺段内的位置。每个槽型测点独立记录导尺至地表、基岩、槽底读数和槽宽。断面数据属于测点，不会重复增加导尺里程。
4. 在“分层与描述”记录地层起止里程、岩矿石名称、产状与现场地质描述。
5. 在“刻槽样品”填写样品编号和起止里程，样长自动汇总。点“拍摄 / 选择照片”用手机相机拍摄或从相册选图；照片会压缩后保存在此设备，并默认命名为“样品编号_序号.jpg”，可直接编辑照片名。
6. 在“导出与备份”导出 Word 原始记录、打印为 PDF、导出 Excel 或下载含样品照片的 JSON 备份。Word 和 PDF 包含样品照片；Excel 的采样登记表含照片名称列。

## 计算口径

- 测点槽深 = 导尺至地表读数 − 导尺至槽底读数；基岩顶面和槽底读数另算覆土厚度、基岩段深度。
- 平均槽深及平均宽度 = 有效测点读数的算术平均值。
- 编录米数 = 各条导尺数据的斜距之和。每条导尺下关联几个槽型测点都不会改变该段里程。
- 刻槽样长 = 每件样品终点里程 − 起点里程，再对各样品长度求和。
- 方量 = 按槽型测点位置排序后，相邻梯形断面面积的平均值 × 区段水平投影长度，逐段累加。断面面积按 (上口宽 + 底宽) × 槽深 ÷ 2 计算；水平投影长度依据槽型测点跨越的导尺段斜距和相应坡度换算。坡度缺失时以斜距近似。测点位置超出所属导尺段或所需数据不全时不显示方量。

## Excel 数据类型

工程编号、导尺编号、槽型测点编号、样品编号、层号及岩性名称作为文本；坐标、尺寸、读数、角度、里程、样长、样品重量和方量作为数值；日期作为 Excel 日期值。编号中的前导零不会被转换成数字。工作簿包含“工程汇总”“导尺数据”“槽型测点”“分层记录”“工程采样登记”五个工作表。

## 依据与边界

导出字段对应 CYPM15-1《工程地质记录表》的工程信息、导尺坐标、分层及样品字段，以及《工程采样及分析结果登记表》的样品编号、野外编号、采样位置、规格、重量、分析结果、导尺方位坡度、区间和样长字段。探槽基点基线、地质观察分层布样、样品标注及记录原则参考用户提供的 DZ/T 0078-2015。应用按本文件所述口径辅助计算工程量，不替代项目设计、测量成果、现场签字检查或规范要求的素描图和照片。
