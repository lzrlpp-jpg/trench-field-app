# 探槽野外编录

可安装到手机主屏幕的离线网页应用。支持多个工程切换、本机自动保存、导尺测点、地质分层、刻槽样登记、工程量汇总和 Word、PDF、Excel 导出。

## 在电脑上打开

1. 安装 Python 3（若电脑已有 Python，可跳过）。
2. 双击 `启动应用.bat`，保持弹出的命令窗口运行。
3. 在电脑浏览器访问 `http://localhost:8765`。

如果双击 `start-local.ps1` 后看到的是脚本代码，请关闭文本编辑器，改为双击 `启动应用.bat`。也可以在 PowerShell 中运行 `.start-local.ps1`。

这个本地地址便于预览和录入；应用数据保存在当前浏览器。换浏览器、清除浏览器数据或换设备前，先在“导出与备份”下载 JSON 备份。

## 在手机上安装

将本文件夹内全部静态文件发布到一个可访问的 HTTPS 网站，再用手机浏览器打开网站。在浏览器菜单中选择“安装应用”或“添加到主屏幕”。首次访问时应用会缓存界面资源；安装后可离线录入与导出。若不部署网站，亦可在手机浏览器访问局域网内的网页地址进行临时使用，但离线安装能力取决于浏览器是否允许该地址使用 Service Worker。

## 现场录入顺序

1. 在“工程概况”填写矿区、工程编号、日期、编录人与采样人。不同探槽可用“新建工程”分别保存，再用工程列表切换。
2. 在“导尺测点”按沿线顺序录入测点。每点记录同一导尺基准至地表、基岩、槽底的垂直读数；同时填写上口宽、底宽。相邻测点记录本段斜距与坡度，起点斜距填 0。坐标、高程、方位及导尺编号可按现场测量录入。
3. 在“分层与描述”记录地层起止里程、岩矿石名称、产状与现场地质描述。
4. 在“刻槽样品”填写样品编号和起止里程，样长自动汇总。
5. 在“导出与备份”导出 Word 原始记录、打印为 PDF、导出 Excel 或下载 JSON 备份。

## 计算口径

- 测点槽深 = 导尺至地表读数 − 导尺至槽底读数；基岩顶面和槽底读数另算覆土厚度、基岩段深度。
- 平均槽深及平均宽度 = 有效测点读数的算术平均值。
- 编录米数 = 各测点本段导尺斜距之和。
- 刻槽样长 = 每件样品终点里程 − 起点里程，再对各样品长度求和。
- 方量 = 相邻测点梯形断面面积的平均值 × 区段水平投影长度，逐段累加。断面面积按 (上口宽 + 底宽) × 槽深 ÷ 2 计算；水平投影长度按斜距 × cos(坡度角) 计算。坡度缺失时以斜距近似。只有测点断面及区段斜距齐全时才显示方量，避免不完整记录产生偏低总量。

## Excel 数据类型

工程编号、导尺编号、样品编号、层号及岩性名称作为文本；坐标、尺寸、读数、角度、样长、样品重量和方量作为数值；日期作为 Excel 日期值。编号中的前导零不会被转换成数字。工作簿包含“工程汇总”“导尺测点”“分层记录”“刻槽样品”四个工作表。

## 依据与边界

界面字段参考用户提供的工程地质记录表与工程采样登记表。探槽基点基线、地质观察分层布样、样品标注及记录原则参考用户提供的 DZ/T 0078-2015。应用按本文件所述口径辅助计算工程量，不替代项目设计、测量成果、现场签字检查或规范要求的素描图和照片。
